# Как запустить проект

## 1. Подготовить файлы

Скачайте репозиторий и положите в одну папку:

- `README.md`;
- `Howtorun.md`;
- `requirements.txt`;
- ноутбук с анализом — например, `T-Bank_Case_code_with_results.ipynb`;
- исходный Excel с листами `Пользователи` и `Платежи`.

Название ноутбука может отличаться. Excel нужен для повторного выполнения расчётов; сохранённые результаты можно изучать без него. Если Excel не включён в репозиторий, его нужно получить отдельно: автоматической загрузки данных в коде нет.

## 2. Установить зависимости

Используйте Python 3.11 или 3.12. В терминале перейдите в папку проекта:

```bash
cd путь/к/папке/проекта
```

Создайте отдельное окружение:

```bash
python -m venv .venv
```

На macOS/Linux вместо `python` может потребоваться `python3`.

Установите зависимости и откройте JupyterLab. Активация окружения не нужна: запускаем его Python напрямую.

**Windows PowerShell:**

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab
```

**macOS/Linux:**

```bash
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python -m jupyterlab
```

Используйте ядро Python из созданного окружения. В `requirements.txt` версии не закреплены: это перечень зависимостей, а не точный снимок исходной среды.

## 3. Исправить путь к Excel

В исходной ячейке загрузки указан локальный Windows-путь автора. Замените две строки `pd.read_excel(...)` следующим кодом; остальную часть ячейки оставьте:

```python
file_path = 'dannye-dlia-keisa-po-pa-cebbefc3-5b29-4f88-b6d4-3336c88d743f.xlsx'

users = pd.read_excel(file_path, sheet_name='Пользователи')
payments = pd.read_excel(file_path, sheet_name='Платежи')
```

Значение `file_path` должно точно совпадать с именем вашего файла, включая суффикс `(1)` или `(2)`, если он есть. Удобнее положить Excel рядом с ноутбуком. Листы и столбцы переименовывать не нужно.

## 4. Выполнить ноутбук

Откройте `.ipynb` в JupyterLab. Перезапустите ядро и выполните все ячейки сверху вниз: **Kernel → Restart Kernel and Run All Cells**.

Порядок важен: сначала загрузка и очистка, затем графики, бутстреп и Z-тест. Для повторного полного запуска начинайте с перезапуска ядра, чтобы не использовать переменные от предыдущих вычислений.

## 5. Сверить результат

На исходном датасете при описанной очистке ожидаются:

| Показатель | Результат |
|---|---|
| Пользователи после очистки | 1503 |
| Попытки после очистки | 2660 |
| Пользователи с попытками | 751 в A, 750 в B |
| Конверсия попыток | 49,81% в A, 64,40% в B |
| Разница B − A | +14,59 п.п. |
| Бутстреп: 95% ДИ разницы | примерно [10,94; 18,24] п.п. |
| Дополнительный Z-тест | Z ≈ 6,386; p ≈ 1,70 × 10⁻¹⁰ |

Бутстреп использует 10 000 повторений и фиксированное начальное состояние генератора. При изменении версии библиотеки или способа генерации случайных чисел границы могут немного отличаться.

Если возникает `FileNotFoundError`, проверьте путь к Excel. Если библиотека не найдена, убедитесь, что ноутбук использует то же окружение, в которое установлены зависимости.
